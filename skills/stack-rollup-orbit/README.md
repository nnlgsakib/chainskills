# stack-rollup-orbit — agent skill

A chainskills stack adapter for **Arbitrum chains** (formerly Orbit) on Nitro. It covers Rollup vs AnyTrust, `@arbitrum/chain-sdk` deployment (RollupCreator → TokenBridgeCreator), nodes and batch posting, BoLD validation and the challenge period, custom gas token and fees, AEP licensing (10% of protocol net revenue outside Arbitrum One/Nova), ArbOS upgrades, and Stylus.

- Versions verified (2026-11-25): Nitro v3.12.4, `@arbitrum/chain-sdk` v0.28.0
