# stack-rollup-op — agent skill

A chainskills stack adapter for **OP Stack** rollups. It covers op-deployer intents and L1 contracts, op-node + op-reth sequencers (op-geth is end-of-support), batcher, proposer, challenger and dispute-mon, Kona fault proofs and ZK dispute games, op-conductor HA sequencing, custom gas token, Alt-DA, Superchain interop (op-supernode), and production launch.

- Versions verified (2026-11-25): op-deployer v0.9.0, op-contracts v9.0.0, op-node v1.20.2, op-reth v2.9.0, op-batcher v1.18.1, op-proposer v1.17.1, op-challenger v1.12.0, op-conductor v0.9.6, op-supernode v1.1.2, kona-node v1.11.0
