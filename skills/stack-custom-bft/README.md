# stack-custom-bft — agent skill

A chainskills stack adapter for **custom chains on a BFT engine**. It covers CometBFT ABCI 2.0 apps in any language, Rust ABCI (tendermint-rs), Malachite (channel, actor or core integration) and Commonware primitives, with determinism rules and the list of components you must build yourself.

- Versions verified (2026-11-25): CometBFT v0.40.0 / v0.38.x, Malachite (arc-malachitebft-*, alpha), Commonware
