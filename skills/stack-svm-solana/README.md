# stack-svm-solana — agent skill

A chainskills stack adapter for **Solana and the SVM**. It covers Anchor or native programs, the Agave CLI and local validator, deployment and upgrade authority, compute budget and priority fees, Token-2022, and testing with LiteSVM, Mollusk and Surfpool (bankrun is deprecated), plus pointers for your own SVM chain.

- Versions verified (2026-11-25): Agave v4.4.1, Anchor v1.2.2
