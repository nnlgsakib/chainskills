# stack-rollup-zk — agent skill

A chainskills stack adapter for **ZK rollups and validiums**, starting with ZK Stack (ZKsync). It covers the ZKsync OS server, the zkstack CLI (ecosystem, chain, gateway, prover), Bridgehub/CTM ownership, the Airbender prover, rollup vs validium, custom base tokens, Gateway settlement and Prividium. It points to OP Succinct and Agglayer CDK, and suggests `build-stack-adapter` for other ZK stacks.

- Versions verified (2026-11-25): zksync-os-server v0.23.0, era-contracts v0.31.x, zksync-era core-v31.5.0
