# protocol-rollup — agent skill

Designs L2/L3 rollups without assuming a framework: rollup type, settlement, data availability, proof system, sequencing and preconfirmations, bridge and forced inclusion, upgrade keys and Security Council, operator roles, and a decentralization-stage target checked against the current ETHBEAT (formerly L2BEAT) Stages spec.

```
protocol-rollup/
├── SKILL.md
└── references/  stages.md · proof-systems.md · risks.md
```

Stages requirements are taken from the forum spec as of 2026-11-25. That includes the 30 Apr 2026 change of the Stage 1 challenge period from 7 to 5 days. Part of the chainskills suite ([install](../../README.md#install)). MIT license.
