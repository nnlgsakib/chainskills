# stack-substrate-sdk — agent skill

A chainskills stack adapter for the **Polkadot SDK** (Substrate/FRAME/Cumulus). It covers parachains with coretime (bulk or on-demand) and solo chains, FRAME pallets, polkadot-omni-node and chain-spec-builder, Pop CLI, weights and benchmarking, forkless runtime upgrades, zombienet-sdk/chopsticks testing, and Polkadot Hub contracts (pallet-revive: REVM + PolkaVM).

- Versions verified (2026-11-25): polkadot-stable2609-2 (node v1.25.2, polkadot-omni-node 0.25.0, frame-omni-bencher 0.29.0, pallet-revive 0.22.0)
